# DSA — One Problem at a Time

I'm using this repo to get better at problem-solving, one question at a time.

I'll be solving Data Structures and Algorithms problems in Java, keeping track of what I learn, what doesn't work at first, and how I improve my solutions.

No rush to solve hundreds of problems overnight. The goal is to understand the logic, write cleaner code, and get a little better every day.

## What's in this repo?

- **Solutions:** Problems I've worked through, with readable Java code.
- **Approaches:** The logic behind each solution, not just the final answer.
- **Complexity:** Time and space complexity wherever relevant.
- **Progress:** A record of my DSA practice as I go.
